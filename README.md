# Дети Эльтана — мод для Космических Рейнджеров 2

> **Каноническая ветка: `master`.** Репозиторий перешёл от концепции самостоятельной KR3 WebGL-игры к разработке крупного сюжетно-системного мода для **Космических Рейнджеров 2 / Space Rangers HD** под названием **«Дети Эльтана»**.

## Новый статус проекта

**«Дети Эльтана» — это не отдельная игра и не попытка заново переписать движок Космических Рейнджеров.**

Главная цель проекта — использовать существующую игровую основу КР2/SRHD как runtime и создать поверх неё новую кампанию, новый лор, новые системные события, квесты, фракционные взаимодействия, оборудование и доступные через моддинг механики.

Старая самостоятельная WebGL-версия остаётся в репозитории как **legacy prototype / design laboratory**. Её код, механики, данные, тесты и UX-наработки можно использовать как спецификацию и источник оригинальных идей, но она больше не является основной платформой разработки.

## High Concept

События происходят примерно через 250 лет после КР2. Галактика сталкивается с новой угрозой — Махпеллами и «Исказителем Реальности». В центре истории находится древнее гаальское пророчество о **Детях Эльтана** и попытка собрать невозможный союз между старыми расами, новыми гибридными цивилизациями, силами Келлера и существами из других слоёв пространства.

Игрок остаётся рейнджером: торгует, воюет, выполняет задания, путешествует по живой галактике КР2 и постепенно втягивается в новую большую кампанию.

## Архитектурный принцип

```text
Space Rangers 2 / Space Rangers HD
            ↓
      base game runtime
            ↓
      Children of Eltan mod
   ├─ quests / text adventures
   ├─ data / balance / equipment
   ├─ factions / reputation / events
   ├─ story campaign / lore
   ├─ mod scripts / configuration
   └─ tooling / validation / packaging

Legacy WebGL KR3 prototype
            ↓
 reference implementation / mechanics lab
```

Базовую механику, уже качественно реализованную КР2, **не нужно переписывать заново**, если её можно переиспользовать через моддинг. Новая собственная реализация допускается только для того, что невозможно выразить средствами КР2/SRHD или внешних совместимых инструментов.

## Что теперь является canonical development track

1. Исследовать реальные возможности и ограничения моддинга КР2/SRHD.
2. Зафиксировать поддерживаемые форматы, инструменты, загрузчики и структуру мода.
3. Создать минимальный устанавливаемый **Children of Eltan mod package**.
4. Перенести в него первую оригинальную сущность проекта: квест, событие, предмет, фракционный контент или сюжетный эпизод.
5. Постепенно переносить концепции из старого KR3/WebGL-прототипа только там, где они органично работают внутри КР2.
6. Каждый новый инкремент проверять в контексте совместимости с базовой игрой и существующей мод-экосистемой.

## Repository Map

- `README.md` — текущая концепция и точка входа.
- `docs/MOD_ARCHITECTURE.md` — каноническая архитектура мода и правила миграции.
- `docs/ROADMAP.md` — roadmap новой mod-first разработки.
- `docs/PROJECT_CONSTITUTION.md` — канонический лор и дизайн-ядро; технические утверждения старой standalone-концепции считаются историческими, если противоречат этому README и `MOD_ARCHITECTURE.md`.
- `docs/KR2_MECHANICS_PARITY_MATRIX.md` и `docs/KR2_EXHAUSTIVE_FEATURE_AUDIT.md` — теперь не список того, что нужно переписать, а карта возможностей КР2, которые желательно **переиспользовать**.
- `quests/` — будущая основа сюжетного и текстового контента мода.
- `data/` — оригинальные данные проекта, пригодные для адаптации к форматам КР2.
- `game/webgl/` — **legacy prototype**, сохранённый для исследования механик и прототипирования; не canonical shipping runtime.
- `scripts/` — инструменты миграции, сборки, проверки и упаковки.

## Agent Quick Start

Перед любым изменением AI-агент обязан:

1. прочитать свежий `README.md`;
2. прочитать `docs/MOD_ARCHITECTURE.md`;
3. прочитать `docs/ROADMAP.md`;
4. проверить последние коммиты в `master`;
5. изучить фактические доступные инструменты/форматы моддинга КР2 перед реализацией;
6. не начинать новую standalone/WebGL-механику только потому, что она есть в старом roadmap;
7. выбрать один небольшой проверяемый mod-first инкремент.

## Правила разработки

- `master` — единственная каноническая ветка.
- Не удалять старый WebGL runtime без отдельного решения: он содержит полезные оригинальные наработки.
- Не считать WebGL/APK релиз основной целью проекта.
- Не копировать чужой закрытый код или защищённые ассеты из КР2/модов в репозиторий без понятного разрешения/лицензии.
- Предпочитать data-driven модификации, скрипты, квесты, конфигурации и инструменты, совместимые с установленной КР2/SRHD.
- Один агентный проход = один небольшой связный инкремент.
- Если возможность моддинга не подтверждена, сначала исследование/документирование, затем код.
- Старая логика «достичь полного parity с КР2 путём переписывания» отменена. Теперь КР2 — сама базовая реализация этих механик.

## Лор, который сохраняется

Смена технологии **не отменяет «Детей Эльтана» как творческий проект**. Сохраняются и адаптируются:

- Махпеллы и «Исказитель Реальности»;
- Келлер и глубокий гипер;
- гибридные цивилизации;
- Теневые Флоты;
- Smart Diplomacy / Alliance Grid как направление, если это технически реализуемо;
- крупные текстовые квесты;
- динамические последствия выбора игрока;
- новое оборудование, события, персонажи и сюжетные арки.

## Ближайшая инженерная цель

Не добавлять очередную механику в WebGL. Следующий технический этап — **определить точный поддерживаемый путь моддинга КР2/SRHD и создать минимальный каркас устанавливаемого мода «Дети Эльтана»**.

---

История standalone KR3 остаётся частью истории проекта, но с этого момента **shipping target проекта — мод «Дети Эльтана» для КР2/SRHD**.
