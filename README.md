# Дети Эльтана — мод для «Космических рейнджеров 2»

> **Каноническая ветка: `master`. Канонический продукт: мод КР2 «Дети Эльтана».**

Этот репозиторий больше не рассматривает самостоятельную WebGL-игру как основную цель. Проект переориентирован на создание крупного сюжетно-системного мода для **«Космических рейнджеров 2» / Space Rangers HD**, рабочее название и название релиза — **«Дети Эльтана»**.

## Концепция

Действие происходит примерно через 250 лет после событий КР2. Галактика сталкивается с новой угрозой, связанной с Махпеллами, Исказителем Реальности, глубоким гиперпространством и наследием Келлера. Игрок остаётся рейнджером внутри знакомой системной основы КР2, но получает новую кампанию, новые цепочки событий, персонажей, фракционные конфликты, оборудование, тексты, квесты и расширенный лор.

Главный принцип миграции: **не переписывать заново то, что уже хорошо делает движок КР2**. Репозиторий должен использовать доступные возможности моддинга КР2 и сосредоточиться на оригинальном контенте и тех механиках, которые реально можно расширить через мод-инструменты.

## Статус проекта

- **Основной продукт:** мод КР2 «Дети Эльтана».
- **Основная ветка:** `master`.
- **Основной рабочий каталог мода:** `mod/`.
- **Документация моддинга и совместимости:** `docs/MOD_ARCHITECTURE.md`.
- **План миграции и разработки:** `docs/ROADMAP.md`.
- **Конституция проекта:** `docs/PROJECT_CONSTITUTION.md`.
- **Старый WebGL runtime:** `game/webgl/` — сохранён как legacy-прототип и источник уже спроектированных механик. Он больше не определяет архитектуру продукта и не является обязательной целью релиза.

## Что переносим из прежней KR3-концепции

Сохраняются как творческий канон:

- название **«Дети Эльтана»**;
- эпоха примерно через 250 лет после КР2;
- Махпеллы и Исказитель Реальности;
- поиск/наследие Келлера;
- глубокое гиперпространство и аномальные зоны;
- новая сюжетная кампания;
- расширенная дипломатия, репутация, контракты и фракционные последствия там, где это позволяет КР2;
- новые тексты, квестовые цепочки, оборудование, события, NPC и баланс;
- лучшие идеи из накопленного аудита механик КР2 — теперь не как список для переписывания движка, а как карта возможностей для мода.

## Что больше НЕ является целью

- создание с нуля собственного аналога движка КР2;
- достижение полного parity КР2 через WebGL;
- выпуск самостоятельной браузерной «КР3» как главной версии проекта;
- дублирование базовой торговли, полёта, боёв, оборудования, интерфейсов и других систем КР2 без необходимости.

## Repository map

- `mod/` — каноническая структура будущего мода, его манифесты, данные, скрипты, тексты и ресурсы по мере определения фактического формата моддинга.
- `docs/` — дизайн, лор, сюжет и техническая документация мода.
- `quests/` — исходники и дизайн квестовых цепочек; по мере изучения формата КР2 они должны конвертироваться в совместимый вид.
- `data/` — структурированные проектные данные, пригодные для последующей трансляции в формат КР2.
- `game/webgl/` — legacy-прототип прежней standalone-версии; не удалять без отдельного решения.
- `.github/` — CI/automation. Новые проверки должны постепенно смещаться от «собрать WebGL» к «проверить структуру, данные и пакет мода».

## Правила для AI-агентов

1. Перед изменением читать `README.md`, `docs/PROJECT_CONSTITUTION.md`, `docs/MOD_ARCHITECTURE.md`, `docs/ROADMAP.md` и актуальные материалы по формату моддинга КР2.
2. Работать только в `master`, если явно не сказано иначе.
3. Один проход — один связный проверяемый инкремент.
4. Приоритет: сначала выяснение и фиксация реального формата моддинга КР2, затем минимальный устанавливаемый каркас мода, затем контент.
5. Не придумывать несуществующие форматы файлов/хуки. Если формат неизвестен — документировать гипотезу и источник, а не выдавать её за факт.
6. Не копировать защищённые игровые ассеты, тексты или код. Репозиторий хранит оригинальные материалы проекта и инструкции интеграции.
7. WebGL можно использовать как reference implementation, но новый функционал по умолчанию проектируется для мода КР2.

## Ближайшая техническая цель

Получить подтверждённую карту моддинга КР2: поддерживаемые форматы, загрузчик/установка, сценарии, квесты, таблицы данных, изображения/звук, ограничения движка и совместимость с распространёнными мод-инструментами. После этого `mod/` превращается из нейтрального каркаса в фактическую устанавливаемую структуру «Детей Эльтана».
