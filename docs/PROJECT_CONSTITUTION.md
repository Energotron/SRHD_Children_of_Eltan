# Конституция проекта «Дети Эльтана»

## Статья 1. Канонический продукт

Проект является модом для «Космических рейнджеров 2» / Space Rangers HD. Название проекта и релиза — **«Дети Эльтана»**. Самостоятельная WebGL-игра не является основной целью.

## Статья 2. Source of truth

`master` — единственная каноническая ветка. Актуальное состояние определяется репозиторием, а не старыми чатами, локальными копиями или прежней standalone-концепцией.

## Статья 3. Mod-first

Любая новая механика сначала оценивается относительно возможностей КР2:

- можно ли использовать существующую механику;
- можно ли изменить данные/контент;
- поддерживает ли это реальный mod toolchain;
- можно ли безопасно эмулировать идею без правки движка.

Нельзя переписывать базовую механику КР2 только потому, что прежний WebGL-прототип делал это самостоятельно.

## Статья 4. Никаких выдуманных API

Форматы файлов, хуки, скриптовые интерфейсы и ограничения КР2 должны подтверждаться источником или воспроизводимым экспериментом. Неизвестное помечается как неизвестное.

## Статья 5. Оригинальный контент

Репозиторий не должен распространять чужие защищённые игровые ассеты, код, тексты или музыку без права на распространение. Допустимы оригинальные материалы проекта, метаданные, инструкции интеграции, патчи и иные законные формы моддинга.

## Статья 6. Сохранённый творческий канон

Основой кампании остаются:

- эпоха примерно через 250 лет после КР2;
- «Дети Эльтана»;
- Махпеллы;
- Исказитель Реальности;
- наследие/поиск Келлера;
- глубокий гипер и аномальные пространства;
- союз несовместимых сил галактики;
- системные последствия решений рейнджера.

Конкретная реализация лора может адаптироваться под ограничения движка и моддинга.

## Статья 7. Legacy WebGL

`game/webgl/` сохраняется как reference/prototype. Его нельзя считать текущим release target. Исправления legacy-кода допустимы только если они нужны для сохранности, исследования или переноса механики в мод.

## Статья 8. Проверяемые инкременты

Один агентный проход = один небольшой связный результат. Изменение должно иметь проверяемый критерий готовности. При наличии tooling добавляются тесты/валидаторы.

## Статья 9. Релиз

Основной релиз — устанавливаемый пакет мода для заявленной версии КР2 с инструкцией установки, версией и changelog. Browser build, APK или standalone ZIP не считаются основным релизом «Детей Эльтана».

## Статья 10. Приоритеты

1. Реальная совместимость с КР2.
2. Стабильная установка и загрузка мода.
3. Сюжетный вертикальный срез.
4. Контент и системные расширения.
5. Полная кампания.
6. Полировка, совместимость и релиз.

Эта конституция заменяет прежние правила, которые определяли `game/webgl/` как канонический runtime.
