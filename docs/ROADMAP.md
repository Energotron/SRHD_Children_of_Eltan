# Roadmap — «Дети Эльтана»

## Фаза 0 — Переход проекта на мод КР2

- [x] Зафиксировать новый канон: «Дети Эльтана» = мод КР2.
- [x] Перевести README и архитектурные документы на mod-first модель.
- [x] Сохранить WebGL как legacy/reference, а не основной runtime.
- [ ] Собрать подтверждённую карту моддинга КР2 и используемых инструментов.
- [ ] Определить поддерживаемые версии КР2 / Space Rangers HD.
- [ ] Зафиксировать юридически безопасные правила по ассетам и зависимости от оригинальной игры.

## Фаза 1 — Минимальный устанавливаемый мод

- [ ] Подтвердить реальную файловую структуру мода.
- [ ] Создать минимальный `mod/` пакет, который игра видит без ошибок.
- [ ] Добавить manifest/version/changelog в формате, поддерживаемом выбранным mod toolchain.
- [ ] Сделать воспроизводимый build/package script.
- [ ] Добавить CI, который валидирует именно модовый пакет.

**Definition of Done:** чистая установка КР2 + пакет «Дети Эльтана» → игра стартует и подтверждает подключённый мод без ручного редактирования репозитория.

## Фаза 2 — Вертикальный срез кампании

- [ ] Новое вступление эпохи «250 лет спустя».
- [ ] Один стартовый сюжетный хук «Детей Эльтана».
- [ ] Один новый персонаж/контакт.
- [ ] Одна полноценная квестовая цепочка.
- [ ] Один уникальный предмет/оборудование или другой подтверждённо модифицируемый контент.
- [ ] Репутационное или фракционное последствие выбора игрока.

**Definition of Done:** игрок может начать кампанию и пройти 30–60 минут нового связного контента внутри КР2.

## Фаза 3 — Системное расширение

В порядке реальной доступности mod API/data formats:

- стартовые архетипы рейнджера;
- новые цепочки контрактов;
- расширенная дипломатия и последствия;
- новые товары/оборудование;
- новые NPC/фракционные роли;
- события, новости и слухи;
- новые текстовые квесты;
- баланс экономики и боёв;
- контент глубокого гипера, если движок позволяет.

## Фаза 4 — Большая кампания

- Махпеллы и Исказитель Реальности;
- линия Келлера;
- формирование альянса;
- крупные фракционные развилки;
- несколько финальных маршрутов;
- оригинальный саунд/арт только с подтверждёнными правами;
- тестирование сохранений и совместимости.

## Фаза 5 — Release Candidate

- чистая установка на поддерживаемую версию игры;
- migration/update path между версиями мода;
- отсутствие обязательных ручных правок;
- полный changelog;
- installation/uninstallation guide;
- smoke test ключевых квестов;
- проверка отсутствия чужих защищённых ассетов в репозитории/релизе;
- пакет GitHub Release.

## Приоритет агентной разработки

Каждый автоматический проход выбирает один маленький инкремент в следующем порядке:

1. блокирующая проблема установки/совместимости мода;
2. подтверждение неизвестной части формата КР2;
3. сборочный/валидационный tooling;
4. завершение уже начатого контента;
5. одна новая высокоценная часть кампании.

Не добавлять новые WebGL-фичи только ради parity. Старый `docs/KR2_MECHANICS_PARITY_MATRIX.md` теперь трактуется как **инвентаризация возможностей и идей для адаптации**, а не план переписывания КР2 с нуля.
