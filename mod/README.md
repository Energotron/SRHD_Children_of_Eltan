# `mod/` — канонический пакет «Дети Эльтана»

Этот каталог — основная релизная область проекта.

## Что уже подтверждено

Для Space Rangers HD реальный файловый корень пользовательских модов — каталог игры `Mods/`. Проверенные публичные примеры устанавливаются отдельной подпапкой внутри `Mods`, а SRHD XenoModKit 0.10.2 использует именно корень `Mods` для `release deploy` / `project deploy` и умеет анализировать `Mods/ModCFG.txt` и effective load order.

Поэтому будущий релиз «Детей Эльтана» должен разворачиваться как отдельный каталог внутри `Space Rangers HD/Mods/`, а не как WebGL/APK-приложение.

## Что ещё НЕ считаем подтверждённым

Точный минимальный набор runtime-файлов нового мода, обязательные поля `ModuleInfo`, способ безопасной активации/записи в `ModCFG.txt` и совместимая версия SRHD должны быть проверены воспроизводимым smoke-test в установленной игре. До этого не придумывать собственную «готовую для игры» схему.

## Рабочие области исходников

- `manifest/` — проектные метаданные версии и совместимости до трансляции в подтверждённый runtime-формат;
- `data/` — структурированные исходные данные;
- `quests/` — исходники квестов и сценариев;
- `text/` — оригинальные тексты и локализация;
- `assets/` — только оригинальные/разрешённые ресурсы;
- `scripts/` — преобразование и сборка;
- `tools/` — валидаторы.

Эти каталоги остаются организационным слоем репозитория и не объявляются реальной структурой SRHD-мода, пока соответствующая точка загрузки не подтверждена.

## Текущий toolchain-кандидат

`Xenomorphchyma/SRHD-XenoModKit` 0.10.2 подтверждает headless-аудит/сборку DAT, SCR/RSON/RSM, QM/QMM, GI/GAI/HAI/PKG, кодировок, структуры мода, `ModuleInfo` и `ModCFG.txt`/load order. Он используется как проверенный tool-assisted источник, но финальная совместимость каждого пакета определяется запуском в игре.

Следующий milestone: минимальный legally-clean `ChildrenOfEltan` skeleton, который присутствует в effective load order и запускается на зафиксированной версии SRHD без ошибок.
