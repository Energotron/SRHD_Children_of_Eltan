# `mod/` — канонический пакет «Дети Эльтана»

Этот каталог — новая основная область разработки проекта.

Пока точная файловая структура моддинга КР2 не подтверждена, здесь хранится только нейтральный каркас и оригинальные исходники проекта. Не добавляйте выдуманные «готовые для игры» форматы без подтверждения.

## Планируемые разделы

- `manifest/` — метаданные версии и совместимости;
- `data/` — структурированные данные;
- `quests/` — квестовые пакеты;
- `text/` — оригинальные тексты и локализация;
- `assets/` — оригинальные/разрешённые ресурсы;
- `scripts/` — преобразование и сборка;
- `tools/` — валидаторы.

Первый технический milestone — заменить этот нейтральный каркас подтверждённой структурой реального устанавливаемого мода КР2.
